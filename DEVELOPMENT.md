# Development

Use the existing checkout at `/workspace/FrameTrace`. Each cloud task is isolated;
create no extra Git worktree unless explicitly requested.

## Prerequisites

Python 3.12+, Node 22.13+ (24 also supported here), npm, FFmpeg/FFprobe, and Docker Compose.
Install Python packages from `services/api/requirements-dev.lock`, then the editable package
with `--no-deps`. The mobile package-lock pins npm dependencies. In this managed machine,
use `UV_CACHE_DIR=/workspace/.cache/uv` and `npm_config_cache=/workspace/.cache/npm` because
the default home caches are read-only. Keep TLS and signature verification enabled.

## Full local services

```sh
docker compose build api
docker compose up -d --wait postgres redis
docker compose up -d api worker
```

On this cloud proxy, build with the system CA supplied only as a BuildKit secret:

```sh
docker build --secret id=proxy_ca,src=/etc/ssl/certs/ca-certificates.crt \
  -f infrastructure/Dockerfile -t frametrace-api:local .
docker compose up -d api worker
```

The Dockerfile runs as an unprivileged user. Services bind to loopback by default.
Compose's database password is intentionally public local-development configuration.
Do not reuse it in a hosted deployment. API and workers share a private named media volume.
Database tables initialize when the API starts; wait for `/health` before ingestion.

```sh
curl --fail http://127.0.0.1:8000/health
.venv/bin/python scripts/make_fixtures.py var/fixtures
docker compose cp var/fixtures/reference.mp4 api:/app/var/reference.mp4
docker compose exec api python -m frametrace.cli ingest /app/var/reference.mp4 \
  --title 'Generated fixture 42' --publisher FrameTrace \
  --rights-basis 'Original synthetic test footage generated by scripts/make_fixtures.py'
.venv/bin/python scripts/smoke_api.py
```

Ingestion is deliberately an operator CLI, not a publicly writable catalog endpoint.
A repeated content hash is rejected; don't reingest or reactivate revoked media blindly.
Only submit media you have permission to process. No user query enters the reference catalog.

For authorized media, pass an independently checked HTTPS `--source-url` if available.
Revoke with `python -m frametrace.cli revoke ID`. Revocation invalidates old result candidates.
Run `python -m frametrace.cli cleanup` periodically (at least hourly in deployment) to expire
job metadata and abandoned raw clips after the configurable default 24 hours. Successful
and failed workers delete their query immediately. Automatic scheduling is not yet installed.

## Native mobile development

```sh
cd apps/mobile
npm ci
# Create .env using .env.example; set EXPO_PUBLIC_API_URL to a device-reachable API.
npm run typecheck
npx expo install --check
npx expo start --dev-client
```

Use a trusted development network or authenticated HTTPS tunnel to reach the backend from
a physical device. Loopback on a phone points to the phone. The default Compose binding
cannot be reached from another device; configure an explicit development binding/tunnel.
Use HTTPS for hosted APIs. Cleartext development networking may require development-only
native configuration; never weaken release network policy.

If Expo's online compatibility endpoint is blocked, `EXPO_OFFLINE=1 npx expo install --check`
checks versions against the installed SDK's bundled native-module manifest. It does not
perform the React Native Directory's online maintenance check. Request `api.expo.dev`
and `reactnative.directory` access in environment settings when needed; do not bypass policy.

```sh
npx expo export --platform android --platform ios
# With your own EAS project and signing/provisioning configured:
npx eas-cli build --profile development --platform android
npx eas-cli build --profile development --platform ios
```

Bundle export is not a signed native build, an install, or a device test. The package IDs
are placeholders pending ownership and branding checks. No store publication is configured.

## Fast backend-only iteration

`FRAMETRACE_EXECUTION=local .venv/bin/uvicorn frametrace.app:app` uses SQLite and in-process
background work. It is not durable under restarts. Default execution is Celery; forgetting
to start Redis and a worker will leave jobs queued or fail submission. See TESTING.md.
